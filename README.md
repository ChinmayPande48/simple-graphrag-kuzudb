# simple-graphrag-kuzudb



A minimal **GraphRAG** (Graph Retrieval-Augmented Generation) implementation using **KùzuDB**.  

This project demonstrates how to store data in a graph database, query it effectively, and use the retrieved graph context to enhance Large Language Model (LLM) responses.



---



## 🚀 Features



- Build a **knowledge graph** using [KùzuDB](https://kuzudb.com/).

- Query the graph with natural language (translated into Cypher-like queries).

- Integrate results into **RAG pipelines** for LLM applications.

- Simple CRUD utilities for graph construction.

- Extendable to **vector search** and **hybrid retrieval** (graph + embeddings).
